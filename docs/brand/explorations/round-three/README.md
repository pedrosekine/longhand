Historical finishing studies from 17 October 2026. Pedro chose A2 and authorised
subtle refinements plus a launcher trial. **Open cuts is the active refinement.**
Use the current canonical assets in [the logo source of truth](../../README.md);
exports in this folder are historical snapshots.

- **Original A2:** depth 8.8, valley exponent 5.0; exact round-two reference.
- **Softer cuts:** depth 8.4, exponent 4.3; shallower and more rounded.
- **Open cuts:** depth 9.4, exponent 4.4; slightly deeper and wider.

All retain fivefold symmetry, orientation, outer radius, and one-colour rendering.
The open-cut version is the launcher trial. Original and softened versions remain
available, along with the retired page launcher icon. The user selected the A2
design; the agent selected Open cuts for the authorised trial. Product-wide
rollout and final optical sign-off remain open.
